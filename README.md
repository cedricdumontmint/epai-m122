# m122 — Automatiser des procédures à l'aide de scripts

Dépôt du cours : **tous les supports** (théorie, présentations, exercices) sont
publiés ici, session après session.

## Avant de commencer

1. Un compte GitHub, Git et Docker installés (voir la session 1).
2. Cloner ce dépôt : `git clone https://github.com/cedricdumontmint/epai-m122.git`
3. À chaque session : `git pull` pour récupérer les nouveaux documents.

## Organisation

- `sessions/sNN/` — pour chaque session : théorie (PDF), présentation (HTML),
  exercices (PDF) et fichiers de départ
- `data/sNN/` — jeux de données de la session
- `labs/` — l'environnement de TP (Docker Compose)

Vos propres travaux vont dans **votre** dépôt personnel, pas ici.
