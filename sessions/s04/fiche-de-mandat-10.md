# Fiche de mandat (dix questions)

**Mandant** : …  
**Date** : …  
**Rédigée par** : …

Une fiche de mandat se remplit **avant** d'écrire la moindre ligne de script, et avant de dessiner :
elle dit ce qu'on attend, pour qui, et à quel moment on pourra dire « c'est réussi ». Les questions 8
et 9 donnent les **décisions** et les **couloirs** du diagramme ; la question 10 donnera les **cas de test**.

| N° | Question | Réponse |
|----|----------|---------|
| 1 | **Quoi ?** La tâche à automatiser, en une phrase. Que se passe-t-il aujourd'hui, étape par étape ? | |
| 2 | **Qui ?** Qui lance la tâche ? Qui lit le résultat (une personne, un autre programme) ? | |
| 3 | **Quand, combien ?** À quelle fréquence ? Combien de temps cela prend-il aujourd'hui ? | |
| 4 | **Pourquoi ?** Quel problème règle-t-on ? Quel gain attend-on ? Cela vaut-il la peine (gain contre coût) ? | |
| 5 | **Entrées** Quelles données (fichiers, paramètres, saisie) ? Où se trouvent-elles ? Un exemple réel ? | |
| 6 | **Sorties** Que doit produire le script (texte à l'écran, fichier, journal) ? Où, sous quelle forme ? | |
| 7 | **Environnement** Bash ou PowerShell ? Quels droits, quels outils, quel dossier d'installation ? | |
| 8 | **Cas particuliers et risques** Que se passe-t-il si l'entrée manque, est vide, contient des espaces ou des accents ? Que peut-on casser ? | |
| 9 | **Interactions** Le script pose-t-il des questions, ou tourne-t-il seul ? Quels messages affiche-t-il ? | |
| 10 | **Terminé quand…** À quoi reconnaît-on que le script est réussi ? Qui valide ? | |

## Décision (question 4)

- Temps gagné par an = temps d'une exécution à la main × nombre d'exécutions par an : … minutes
- Temps pour écrire et tester le script : … minutes
- Je recommande d'automatiser : **oui** / **non** / **peut-être**, parce que : …
