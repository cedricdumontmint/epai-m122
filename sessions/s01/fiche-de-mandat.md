# Fiche de mandat

**Mandant** : …  
**Date** : …  
**Rédigée par** : …

Une fiche de mandat se remplit **avant** d'écrire la moindre ligne de script : elle dit ce
qu'on attend, pour qui, et à quel moment on pourra dire « c'est réussi ».

| N° | Question | Réponse |
|----|----------|---------|
| 1 | **Quoi ?** La tâche à automatiser, en une phrase | |
| 2 | **Qui ?** Qui lance la tâche ? Qui lit le résultat ? | |
| 3 | **Quand, combien ?** À quelle fréquence ? Combien de temps cela prend-il aujourd'hui ? | |
| 4 | **Pourquoi ?** Quel gain attend-on ? Cela vaut-il la peine ? | |
| 5 | **Entrées et sorties** Que faut-il lire ? Que faut-il produire, et où ? | |
| 6 | **Terminé quand…** À quoi reconnaît-on que le script est réussi ? | |

## Calcul de rentabilité

- Temps gagné par an = temps d'une exécution à la main × nombre d'exécutions par an : … minutes
- Temps pour écrire et tester le script : … minutes
- Le script est amorti après … exécutions
